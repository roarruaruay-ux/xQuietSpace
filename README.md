# QuietSpace

เว็บห้องอยู่ด้วยกันแบบเงียบๆ: สร้างเซิร์ฟเวอร์ของตัวเองและชวนเพื่อนด้วยลิงก์ เพิ่มเพื่อน แชตส่วนตัว ปรับสถานะ
ห้องเสียงอวตาร 3D กล้อง ไมค์ แชร์หน้าจอ และกรอบโปรไฟล์ ใช้ได้จริงข้ามเครื่อง ทำงานบน Cloudflare (Workers + Durable Objects) ทั้งหมด ไม่ต้องมีเซิร์ฟเวอร์ของตัวเอง

## ติดตั้งขึ้นออนไลน์ (ทำครั้งเดียว ประมาณ 10 นาที)

1. ติดตั้ง Node.js เวอร์ชัน LTS จาก https://nodejs.org (กด Next ไปเรื่อยๆ)
2. แตกไฟล์ zip นี้ แล้วเปิดโฟลเดอร์ `QuietSpace`
3. คลิกขวาที่ว่างในโฟลเดอร์ เลือก "Open in Terminal" (Windows 11) หรือพิมพ์ `cmd` ที่แถบที่อยู่ของโฟลเดอร์แล้วกด Enter
4. พิมพ์ทีละคำสั่ง รอให้แต่ละคำสั่งเสร็จก่อน

       npm install
       npx wrangler login
       npx wrangler deploy

   - `wrangler login` จะเปิดเบราว์เซอร์ให้กดอนุญาต ใช้บัญชี Cloudflare เดียวกับที่สมัครไว้
   - ถ้าถามให้ตั้งชื่อ workers.dev subdomain ให้ตั้งชื่ออะไรก็ได้ที่ยังว่าง
5. เสร็จแล้วจะขึ้นลิงก์ เช่น `https://quietspace.ชื่อคุณ.workers.dev` เปิดได้เลย (เป็น https อยู่แล้ว กล้องและไมค์ใช้งานได้)

อัปเดตเว็บภายหลัง: แก้ไฟล์แล้วรัน `npx wrangler deploy` อีกครั้ง

## ลองบนเครื่องตัวเองก่อน (ไม่บังคับ)

    npx wrangler dev

แล้วเปิด http://localhost:8787 เปิดสองแท็บเพื่อลองเข้าห้องเดียวกัน

## ไฟล์สำคัญ

- `public/` หน้าเว็บ (index.html, app.js, logo.png)
- `public/avatar.js` ตัวสร้างอวตาร 3 มิติแบบสร้างสด (ไม่ใช้ไฟล์ภาพ/โมเดล) `public/scenes.js` ฉากหลัง 3 มิติ 6 แบบ และ `public/track.js` ตัวติดตามใบหน้าจากกล้อง ทั้งสามไฟล์ต้องอัปโหลดคู่กับ app.js
- `public/vendor/` ตัวอ่านไฟล์โมเดล 3D (.glb) โหลดเฉพาะตอนมีคนใช้โมเดลของตัวเอง
- `src/hub.js` ระบบหลังบ้านทั้งหมด: บัญชี เซิร์ฟเวอร์ ช่อง เพื่อน แชตส่วนตัว สถานะ แชต สมาชิก Pro ส่วนลด และส่งต่อสัญญาณ WebRTC
- `src/files.js` ที่เก็บและส่งไฟล์ (R2) `src/stripe.js` เชื่อมต่อ Stripe
- `src/worker.js` จุดเข้าของ Cloudflare Worker และ Durable Object
- `wrangler.jsonc` ค่าตั้งค่าการติดตั้ง

## ข้อจำกัดที่ควรรู้

- **บัญชีผูกกับเบราว์เซอร์** ยังไม่มีการสมัครด้วยอีเมลหรือรหัสผ่าน ระบบสร้างบัญชีให้อัตโนมัติและจำด้วยรหัสลับในเบราว์เซอร์ ถ้าล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่องจะเสียบัญชี เว้นแต่คัดลอก "รหัสกู้คืน" ไว้ (หน้า โปรไฟล์ > บัญชีและรหัสเพื่อน) ใครได้รหัสกู้คืนจะเข้าบัญชีนั้นได้ ห้ามส่งให้ใคร
- ภาพ เสียง และหน้าจอส่งตรงระหว่างผู้ใช้ (ไม่ผ่านเซิร์ฟเวอร์) เหมาะกับห้องไม่เกิน 6-8 คน การแชร์หน้าจอหนักกว่ากล้อง ถ้าคนดูเกิน 4 คนอาจกระตุก คนบางเครือข่าย (เช่น เน็ตมือถือบางเจ้า หรือเน็ตองค์กร) อาจต่อกันไม่ติด แก้ได้โดยเปิดใช้ TURN ของ Cloudflare (ด้านล่าง)
- แชร์หน้าจอใช้ได้บนคอมพิวเตอร์ (Chrome, Edge, Firefox, Safari) มือถือส่วนใหญ่ยังแชร์หน้าจอไม่ได้ แต่ดูหน้าจอที่คนอื่นแชร์ได้
- แชตเก็บย้อนหลังล่าสุด 200 ข้อความต่อช่องหรือต่อบทสนทนา ข้อความยาวได้ไม่เกิน 1,000 ตัวอักษร
- สิทธิ์ในเซิร์ฟเวอร์: **เจ้าของ** (คนสร้าง ทำได้ทุกอย่าง และเป็นคนเดียวที่สร้างยศ/มอบยศได้) · **ยศที่เจ้าของสร้างเอง** (เลือกสิทธิ์ได้ 7 อย่าง ดูหัวข้อ ระบบยศ) · **สมาชิกทั่วไป** · **Dev** (ผู้พัฒนา ใช้รหัส Dev ดูแลเซิร์ฟเวอร์กลางได้ทุกอย่าง ดูหัวข้อ รหัส Dev) และ "ผู้ดูแลเว็บ" ที่ลบห้องของเซิร์ฟเวอร์กลางได้ (ดูหัวข้อ ลบห้อง และผู้ดูแลเว็บ) ยังไม่มีปุ่มรายงานผู้ใช้ (มีบล็อก เตะ แบน)
- เซิร์ฟเวอร์กลาง "QuietSpace" เปิดให้ทุกคนที่เข้าเว็บ ผู้ใช้ใหม่จะเข้าไปอยู่ในนั้นอัตโนมัติ (ออกได้) ใครอยู่ในนั้นก็ส่งข้อความส่วนตัวหากันได้ ถ้าไม่อยากให้คนแปลกหน้าทัก ให้บล็อกได้
- ห้ามรบกวนปิดแค่เสียงและข้อความเด้งแจ้งเตือนในหน้าเว็บ (ยังไม่มีแจ้งเตือนผ่านระบบของเบราว์เซอร์เมื่อปิดแท็บ)
- ระบบทั้งหมดรันบน Durable Object ตัวเดียว ยังไม่ได้ทดสอบโหลดกับคนจำนวนมาก เหมาะกับกลุ่มเพื่อนถึงชุมชนขนาดเล็ก ถ้าคนใช้เยอะมากต้องแยกเป็นหลายตัว

## ระบบที่เพิ่มในเวอร์ชันนี้

- **แถบเซิร์ฟเวอร์อยู่ด้านบน** ปุ่มบ้าน = หน้าหลัก (เพื่อนและแชตส่วนตัว) ถัดไปคือเซิร์ฟเวอร์ที่คุณอยู่ กด + เพื่อสร้างหรือเข้าร่วม
- **สร้างเซิร์ฟเวอร์** ตั้งชื่อ เลือกไอคอนและสี ได้ช่องข้อความและช่องเสียงเริ่มต้น เจ้าของสร้างช่องเพิ่มได้ และได้ลิงก์เชิญ (`https://เว็บของคุณ/?invite=รหัส`) ส่งให้เพื่อนเปิดแล้วกดเข้าร่วมได้เลย เปลี่ยนรหัสเชิญใหม่ได้ถ้ารหัสหลุด
- **เพิ่มเพื่อน** ทุกคนมีรหัสเพื่อน 6 ตัว (หน้าโปรไฟล์) หรือกดที่ชื่อคนในเซิร์ฟเวอร์เดียวกันแล้วเลือกเพิ่มเพื่อน มีหน้ารอดำเนินการ ยอมรับ/ปฏิเสธ ลบเพื่อน และบล็อก
- **แชตส่วนตัว (DM)** ส่งข้อความหาเพื่อนหรือคนในเซิร์ฟเวอร์เดียวกัน มีตอบกลับ แก้ไข รีแอคชัน และจุดข้อความที่ยังไม่อ่าน
- **สถานะ** ออนไลน์ ไม่อยู่ (ตั้งเอง หรืออัตโนมัติเมื่อไม่ได้ใช้ 5 นาที) ห้ามรบกวน ล่องหน (ออนไลน์อยู่แต่คนอื่นเห็นเป็นออฟไลน์) กดที่ชื่อตัวเองมุมซ้ายล่างเพื่อเปลี่ยน
- **กรอบโปรไฟล์ 16 แบบ** หน้าโปรไฟล์ > กรอบโปรไฟล์ (ใบไม้ ทอง ม่วงหรู ซากุระ ทะเล น้ำแข็ง เปลวไฟ นีออน กาแล็กซี สายรุ้ง เถาวัลย์ หูแมว หูกระต่าย วงแหวนเทวดา เขาน้อย และไม่ใส่) คนอื่นเห็นกรอบของคุณทั้งในแชต รายชื่อ และห้องเสียง
- **แชร์หน้าจอ** เข้าห้องเสียงแล้วกด "แชร์หน้าจอ" เลือกหน้าจอ หน้าต่าง หรือแท็บ (ถ้าเลือกแท็บใน Chrome แชร์เสียงของแท็บได้ด้วย) คนอื่นในห้องเห็นเป็นจอใหญ่เหนือห้อง 3 มิติ และกดเต็มจอได้
- ข้อมูลเดิมจากเวอร์ชันก่อน (ห้อง แชต สิทธิ์เจ้าของห้อง) ย้ายเข้าเซิร์ฟเวอร์ "QuietSpace" ให้อัตโนมัติตอนอัปเดต ไม่ต้องทำอะไร

| | ฟรี | Pro |
|---|---|---|

| ของตกแต่งอวตาร | ชุดพื้นฐาน | เพิ่มชุด Pro (กรอบพิเศษ หมวก ทรงผม ชุด เครื่องประดับ รวม 28 ชิ้น ไม่นับกรอบ) และ "ตัวสร้างอวตารขั้นสูง" ปรับสัดส่วน ใบหน้า ลวดลาย ออร่า |
| แชร์หน้าจอ | 720p 15 เฟรม/วินาที | **1080p 30 เฟรม/วินาที** ภาพคมขึ้น |
| อัปโหลดไฟล์ในแชต | ไฟล์ละไม่เกิน 10 MB | **ไม่จำกัดขนาดไฟล์** |

**ส่วนลด 10% สำหรับคนใช้งานครบ 100 ชั่วโมง** ลดให้ทุกรอบบิลที่ยังสมัครอยู่ (รายเดือน ฿80.10 รายปี ฿719.10) นับเฉพาะเวลาที่เปิดเว็บและมีการใช้งานจริง (ขยับเมาส์ พิมพ์ กด) ไม่นับตอนเปิดทิ้งไว้ ดูความคืบหน้าได้ในหน้าแพ็กเกจ

ถ้าหมดอายุหรือยกเลิก ของ Pro ที่เคยเลือกไว้จะไม่แสดงให้คนอื่นเห็น (กลับมาแสดงเมื่อต่ออายุ) ไฟล์ที่เคยอัปโหลดยังเปิดได้

### โหมดชำระเงิน 3 แบบ (สำคัญ อ่านก่อนเปิดให้คนทั่วไปใช้)

ระบบเลือกโหมดเองตามที่ตั้งค่าไว้:

| โหมด | เมื่อไหร่ | ผลลัพธ์ |
|---|---|---|
| **โหมดทดลอง (demo)** | ยังไม่ตั้ง `STRIPE_SECRET_KEY` (**ค่าเริ่มต้นตอนดีพลอยครั้งแรก**) | กดสมัครแล้วจำลองการจ่ายเงิน **ไม่ตัดเงินจริง แต่ใครก็ได้เป็น Pro ฟรี** เหมาะกับสาธิตที่บูธ/พรีเซนต์ |
| **Stripe (ของจริง)** | ตั้ง `STRIPE_SECRET_KEY` แล้ว | พาไปหน้าจ่ายเงินของ Stripe ตัดบัตรจริง ต่ออายุอัตโนมัติ |
| **ปิด (off)** | ตั้ง `PAY_MODE` = `off` | ซ่อนการสมัคร ทุกคนใช้แบบฟรี |

> ⚠️ ถ้าปล่อยเว็บไว้ในโหมดทดลองแล้วเปิดให้คนทั่วไปเข้า ทุกคนจะได้ Pro ฟรี ถ้าไม่ต้องการ ให้ตั้ง `PAY_MODE=off` หรือใส่คีย์ Stripe

ในโหมดทดลอง หน้าแพ็กเกจมีปุ่ม **"สาธิต: ข้ามไปใช้งานครบ 100 ชม."** ไว้โชว์ตอนพรีเซนต์ว่าส่วนลดทำงานอย่างไรโดยไม่ต้องรอ 100 ชั่วโมง (ปุ่มนี้มีเฉพาะโหมดทดลอง)

ตั้งค่าตัวแปรที่ Cloudflare Dashboard > Workers & Pages > quietspace > Settings > Variables and Secrets หรือใช้คำสั่ง `npx wrangler secret put ชื่อตัวแปร`

### เชื่อม Stripe (เมื่อพร้อมรับเงินจริง)

1. สมัคร Stripe (https://stripe.com) ยืนยันตัวตนธุรกิจ/บุคคลตามขั้นตอน (เท่าที่ทราบ Stripe ประเทศไทยรองรับการสมัครสมาชิกแบบตัดบัตรอัตโนมัติ ส่วน PromptPay ใช้กับการตัดเงินซ้ำอัตโนมัติไม่ได้ ควรเช็กเงื่อนไขล่าสุดกับ Stripe อีกครั้ง)
2. ลองด้วย **Test mode** ก่อน: Developers > API keys คัดลอก Secret key (ขึ้นต้น `sk_test_...`) แล้วรัน `npx wrangler secret put STRIPE_SECRET_KEY`
3. ตั้ง Webhook: Developers > Webhooks > Add endpoint
   - URL: `https://เว็บของคุณ.workers.dev/api/stripe-webhook`
   - เลือกอีเวนต์: `checkout.session.completed`, `customer.subscription.created`, `customer.subscription.updated`, `customer.subscription.deleted`, `invoice.paid`, `invoice.payment_failed`
   - คัดลอก Signing secret (ขึ้นต้น `whsec_...`) แล้วรัน `npx wrangler secret put STRIPE_WEBHOOK_SECRET`
4. เปิด Customer portal (Settings > Billing > Customer portal) เพื่อให้สมาชิกเปลี่ยนบัตรและดูใบเสร็จได้
5. ลองสมัครด้วยบัตรทดสอบ `4242 4242 4242 4242` (วันหมดอายุอนาคตใดก็ได้ CVC อะไรก็ได้) ถ้าใช้ได้ค่อยสลับเป็น Live key (`sk_live_...`) และสร้าง Webhook ใหม่ของโหมด Live
6. คูปองส่วนลด 10% (รหัส `qs_loyal10`) ระบบสร้างให้อัตโนมัติ ไม่ต้องสร้างเอง

**ข้อควรรู้:** โค้ดส่วน Stripe ทดสอบกับระบบจำลองเท่านั้น ยังไม่เคยทดสอบกับ Stripe จริง ให้ลองในโหมด Test ให้ครบก่อนรับเงินจริงเสมอ และการรับเงินจริงมีข้อกำหนดด้านภาษี/กฎหมายของผู้ขาย ควรปรึกษาผู้รู้

## เปิดระบบอัปโหลดไฟล์ (R2) ต้องทำเองหนึ่งครั้ง

การอัปโหลดไฟล์ในแชตและโมเดลอวตาร์ .glb เก็บไว้ใน Cloudflare R2 ซึ่งต้องเปิดใช้งานเอง (ถ้ายังไม่เปิด ปุ่มแนบไฟล์จะแจ้งว่าระบบยังไม่พร้อม ส่วนอื่นของเว็บใช้ได้ปกติ)

1. Cloudflare Dashboard > Storage & databases > R2 object storage > เปิดใช้งาน (ต้องผูกบัตรเครดิต/เดบิต แต่มีโควตาฟรีรายเดือนก่อน เกินแล้วคิดตามการใช้งานจริง ไฟล์ใหญ่และจำนวนมากจะมีค่าใช้จ่าย)
2. Create bucket ตั้งชื่อ `quietspace-files`
3. เปิดไฟล์ `wrangler.jsonc` ลบเครื่องหมาย `//` หน้าบรรทัด `"r2_buckets": [...]` แล้วดีพลอยใหม่ (ถ้าใช้ GitHub ก็อัปโหลดไฟล์ `wrangler.jsonc` ด้วย)

เรื่องที่ควรรู้: ไฟล์เปิดได้ด้วยลิงก์ที่เดายาก (ใครมีลิงก์ก็เปิดได้ ยังไม่มีการเช็กสิทธิ์รายคน) ไฟล์ที่ไม่ใช่รูป/วิดีโอ/เสียงจะเป็นการดาวน์โหลดเท่านั้น ไม่รันบนหน้าเว็บ ไฟล์ที่อัปโหลดแล้วยังไม่มีระบบลบอัตโนมัติ ควรดูพื้นที่ใน R2 เป็นระยะ

## ลบห้อง และผู้ดูแลเว็บ

**วิธีลบ:** ชี้เมาส์ที่ห้องในรายการด้านซ้ายแล้วกดไอคอนถังขยะ (บนมือถือไอคอนแสดงตลอด) หรือคลิกขวาที่ห้อง (กดค้างบนมือถือบางรุ่น) เลือก "ลบห้องนี้" หรือเข้าห้องแล้วกดปุ่ม "ลบห้องนี้" ที่หัวช่อง จะมีกล่องให้ยืนยันก่อนลบเสมอ ข้อความทั้งหมดในห้องหายถาวร และคนที่อยู่ในห้องเสียงจะถูกพาออก

**ใครลบได้:**

| ห้องไหน | ลบได้โดย |
|---|---|
| ห้องในเซิร์ฟเวอร์ที่คุณสร้าง | เจ้าของเซิร์ฟเวอร์ (ลบได้ทุกห้อง) และคนสร้างห้องนั้น |
| ห้องที่คุณสร้างเองในเซิร์ฟเวอร์กลาง "QuietSpace" | คุณ |
| ห้องเริ่มต้นของเซิร์ฟเวอร์กลาง (ทั่วไป แนะนำตัว ห้องต้อนรับ ห้องอ่านหนังสือเงียบๆ) และห้องที่คนอื่นสร้าง | **ผู้ดูแลเว็บ** เท่านั้น |

เซิร์ฟเวอร์ต้องเหลืออย่างน้อย 1 ห้องเสมอ (ห้องสุดท้ายลบไม่ได้) ผู้ดูแลเว็บ**ไม่มีสิทธิ์**ลบห้องในเซิร์ฟเวอร์ส่วนตัวของคนอื่น

**ตั้งตัวเองเป็นผู้ดูแลเว็บ:**

1. เปิดเว็บ กดรูปเฟืองที่แผงโปรไฟล์ด้านบนซ้าย ดู "รหัสเพื่อนของฉัน" (6 ตัวอักษร เช่น `35RDD9`)
2. Cloudflare Dashboard > Workers & Pages > quietspace > Settings > Variables and Secrets > Add > ชื่อ `ADMIN_CODES` ค่าคือรหัสเพื่อนของคุณ (ใส่หลายคนได้ คั่นด้วยจุลภาค เช่น `35RDD9,K3M7QX`) > Deploy
   (หรือใช้คำสั่ง `npx wrangler secret put ADMIN_CODES`)
3. รีเฟรชเว็บ ในหน้าโปรไฟล์จะขึ้นข้อความ "คุณเป็นผู้ดูแลเว็บ" และห้องเริ่มต้นจะมีถังขยะให้กด

ความปลอดภัย: สิทธิ์ผูกกับ**บัญชี** (ไม่ใช่แค่รู้รหัส) ใครรู้รหัสเพื่อนของคุณก็ไม่ได้สิทธิ์ผู้ดูแล แต่ถ้ามีคนได้ "รหัสกู้คืน" ของบัญชีคุณ จะเข้าบัญชีคุณและใช้สิทธิ์นี้ได้ จึงห้ามส่งรหัสกู้คืนให้ใคร ถ้าเสียบัญชีนั้นไป ให้เปลี่ยน `ADMIN_CODES` เป็นรหัสของบัญชีใหม่
ผู้ดูแลเว็บลบ "ห้อง" ได้อย่างเดียว ถ้าต้องการเตะ แบน ปิดไมค์ ลบข้อความ ฯลฯ ในเซิร์ฟเวอร์กลาง ให้ใช้ยศ Dev (ดูหัวข้อ รหัส Dev)

## แถบความคืบหน้าการอ่าน (ในห้องอ่านหนังสือ)

อยู่ด้านบนของห้องเสียงทุกห้อง เหนือเวทีอวตาร (ไม่ทับกล้องหรืออวตาร) แทนตัวจับเวลาโฟกัสแบบเก่า

**วิธีใช้**

- เลือกเป้า **25 / 45 / 60 นาที** (ค่าเริ่มต้น 45) แล้วกด **เริ่มอ่าน**
- แถบเต็มเมื่อถึงเป้า มีเส้นขีดที่ 25 / 50 / 75% และข้อความให้กำลังใจตอนผ่านแต่ละช่วง พอครบ 100% ขึ้น "อ่านครบแล้ว 🎉" พร้อมเสียงและแอนิเมชันสั้นๆ
- กด **พัก** เพื่อหยุดชั่วคราว (เวลาไม่เดินระหว่างพัก) กด **รีเซ็ต** เพื่อเริ่มใหม่
- กด **สถิติ** เพื่อดูเวลาอ่านวันนี้ กราฟ 7 วันล่าสุด จำนวนวันที่ครบเป้า อ่านต่อเนื่องกี่วัน และเหรียญสะสม (ครบเป้าครั้งแรก, อ่านต่อเนื่อง 3 วัน, รวม 10 ชั่วโมง, ครบเป้า 10 ครั้ง)
- ตัวเลือกในแผงสถิติ: เริ่มนับเองเมื่อเข้าห้องเสียง / ให้คนในห้องเห็นป้ายว่ากำลังอ่าน / ล้างสถิติ (ต้องกดยืนยัน)
- ขณะอ่านจะเห็นเวลาในแผงโปรไฟล์ซ้ายบนและชื่อแท็บเบราว์เซอร์ด้วย ไม่ต้องเปิดห้องค้างไว้บนหน้าจอ

**ป้ายที่เพื่อนเห็น:** 📖 = กำลังอ่าน, 🎉 = อ่านครบเป้า (แสดงต่ออีก 30 นาที) ขึ้นข้างชื่อบนเวทีและในรายชื่อห้องด้านซ้าย ปิดได้ในแผงสถิติ

**นับเวลาอย่างไร (ให้ตรงแม้สลับแท็บ):** เก็บ "เวลาที่กดเริ่ม" (timestamp) แล้วคำนวณเป็นเปอร์เซ็นต์จากเวลาที่ผ่านไปจริง ไม่ได้นับทีละวินาที เวลาจึงไม่เพี้ยนเมื่อสลับแท็บหรือแท็บถูกเบราว์เซอร์หน่วง สถานะและสถิติเก็บใน localStorage ของเบราว์เซอร์ (รีเฟรชแล้วไม่หาย เก็บสถิติย้อนหลัง 120 วัน) ไม่มีการอัปโหลดขึ้นเซิร์ฟเวอร์ ยกเว้นตัวเลขป้ายสถานะ (0–3) ที่ส่งให้คนในห้องเห็น

**ข้อจำกัด (พูดตรงๆ):**

- เป็นเวลาตามนาฬิกาจริงที่ผู้ใช้กดเริ่มเอง ระบบไม่รู้ว่าคุณกำลังอ่านจริงหรือเปิดทิ้งไว้ ป้าย 🎉 จึงเป็นการ "บอกเอง" ไม่ใช่การตรวจสอบ
- ถ้าปิดหน้าเว็บไปนานเกิน 5 นาที ระบบจะพักตัวจับเวลาไว้ที่จุดที่เห็นล่าสุดและไม่นับเวลาช่วงที่หายไป
- สถิติผูกกับเบราว์เซอร์/เครื่องนั้น (ล้างข้อมูลเว็บหรือเปลี่ยนเครื่องแล้วหาย) และไม่ซิงก์ข้ามอุปกรณ์
- ถ้าเปลี่ยนเวลาเครื่องย้อนหลังหรือข้ามวัน ตัวเลขอาจเพี้ยน

## ข้อจำกัดของระบบสมาชิก (พูดตรงๆ)

- **แชร์หน้าจอ 1080p ฝั่งเซิร์ฟเวอร์บังคับไม่ได้** ภาพส่งตรงระหว่างผู้ใช้ จำกัดความคมที่ฝั่งเบราว์เซอร์ ใครแก้เบราว์เซอร์เองก็ข้ามได้ และการแชร์ 1080p ใช้เน็ตและเครื่องมากกว่า คนดูหลายคนอาจกระตุก
- **ชั่วโมงใช้งานนับจากการใช้งานจริง** แต่คนที่เขียนสคริปต์จำลองการใช้งานก็อาจปั๊มชั่วโมงได้ ถ้าจะแจกส่วนลดเป็นวงกว้างควรเพิ่มการตรวจเพิ่มเติม
- **บัญชีผูกกับเบราว์เซอร์** ถ้าเสียบัญชี สมาชิก Pro ก็หายจากบัญชีนั้นด้วย (ต้องใช้รหัสกู้คืน)
- **โมเดล .glb ของผู้ใช้** เป็นไฟล์ที่ไม่ได้ตรวจเนื้อหา อาจมีโมเดลไม่เหมาะสมหรือหนักเครื่องคนอื่น ระบบกันไว้บางส่วน (จำกัดขนาดและจำนวนสามเหลี่ยม คนดูปิดการแสดงโมเดลของคนอื่นได้) แต่ยังไม่มีระบบรายงาน/ตรวจเนื้อหา
- ทุกอย่างยังรันบน Durable Object ตัวเดียว (ดูข้อจำกัดด้านบน)

## เปิดใช้ TURN (ไม่บังคับ ช่วยให้ต่อติดมากขึ้น)

1. ใน Cloudflare Dashboard ไปที่ Realtime แล้วสร้าง TURN key จดค่า Key ID และ API Token
2. รันสองคำสั่งนี้ แล้ววางค่าตามที่ถาม

       npx wrangler secret put TURN_KEY_ID
       npx wrangler secret put TURN_API_TOKEN

ส่วนนี้เขียนไว้ตามเอกสารของ Cloudflare แต่ยังไม่ได้ทดสอบกับบัญชีจริง

## เสียงบรรยากาศ
ในห้องมีปุ่ม "เสียงบรรยากาศ": ฝน ฝนฟ้าร้อง ใบไม้ ลม คลื่น ลำธาร เตาผิง จิ้งหรีด และนอยส์ขาว/ชมพู/น้ำตาล เปิดผสมกันได้ ปรับระดับแยกได้ มีชุดสำเร็จรูป และอัปโหลดไฟล์เสียงของตัวเองได้ (สูงสุด 5 ไฟล์) เสียงสร้างสดในเบราว์เซอร์และได้ยินเฉพาะคนที่เปิด ไม่ส่งให้คนอื่น

## รูปโปรไฟล์
ในหน้า "อวตารของฉัน" เลือกรูปสำเร็จรูป 10 แบบ หรืออัปโหลดรูปของตัวเองได้ (ระบบครอปเป็นสี่เหลี่ยมจัตุรัสและย่อเหลือ 96 พิกเซลในเครื่อง ก่อนส่งให้คนในห้อง) รูปแสดงข้างชื่อเหนืออวตารและในรายชื่อคนในห้อง

## ฉากหลังและอวตารรุ่นใหม่ (v2)
- **ฉากหลัง 3 มิติ 6 แบบ** (ปุ่ม "พื้นหลัง" ในห้องเสียง): แสงเหนือ (ค่าเริ่มต้น), ป่าเรืองแสง, ทะเลหมอก, ดาราจักร, ทะเลสาบยามเย็น, ซากุระรุ่งอรุณ สร้างสดด้วยโค้ดทั้งหมด ไม่ต้องโหลดรูปหรือโมเดลเพิ่ม ใช้ได้ทั้งห้องเสียงและหน้าอวตารของฉัน ส่วนรูปที่ผู้ใช้อัปโหลดเองจะแสดงเป็นพื้นหลังจริงพร้อมแท่นเรียบให้ตัวละครยืน (ปรับความมืดได้ทุกแบบ ความเบลอใช้กับรูปอัปโหลดเท่านั้น)
- **คุณภาพภาพปรับเอง**: มือถือหรือเครื่องแรมน้อยเริ่มที่โหมดประหยัด (ปิดเงาจริง ลดอนุภาค) และทุกเครื่องจะลดคุณภาพอัตโนมัติถ้าภาพกระตุกต่อเนื่อง
- **อวตารสร้างใหม่ทั้งหมด**: สัดส่วน ผิว ผม ดวงตา และแสงเงาสมจริงขึ้น ทรงผม/หมวก/ชุด/ของประกอบทุกชิ้นคำนวณให้พอดีกับศีรษะและลำตัว สวมซ้อนกันได้ทุกคู่โดยไม่ทะลุกัน (ตรวจด้วยโปรแกรมทดสอบการทะลุ 1,000+ คู่) ข้อจำกัดที่รู้: ลายเสื้อ (ขวาง/จุด/ตาราง) ใช้ได้กับเสื้อทั่วไป ไม่ใช้กับชุดเกราะและชุดนักบินอวกาศ
- **หน้าสมัคร Pro เลื่อนดูรายละเอียดได้** ทั้งคอมพิวเตอร์และมือถือ

## ต้องตั้งชื่อก่อนใช้งาน
- ผู้ใช้ใหม่จะเจอหน้าต่างให้ **ตั้งชื่อก่อนเสมอ** ปิดไม่ได้ (กด Esc ก็ปิดไม่ได้) จนกว่าจะตั้งชื่อที่ไม่ใช่ค่าเริ่มต้น ชื่อ "ผู้มาใหม่" และ "ผู้มาใหม่ 2" ใช้ไม่ได้ ชื่อว่างหรือมีแต่ช่องว่างก็ไม่ได้ เพื่อให้ไม่มีคนชื่อซ้ำกันจนแยกไม่ออก
- ฝั่งเซิร์ฟเวอร์ตรวจซ้ำด้วย: ถ้ายังไม่มีชื่อจริง จะส่งข้อความ ขอเป็นเพื่อน สร้าง/เข้าเซิร์ฟเวอร์ หรือสมัคร Pro ไม่ได้ (แก้ด้วยการแก้โค้ดหน้าเว็บไม่ได้ผล)
- คนที่ใช้งานอยู่ก่อนหน้านี้และยังชื่อ "ผู้มาใหม่" ก็จะเจอหน้าต่างนี้ตอนเปิดครั้งถัดไป ส่วนคนที่ตั้งชื่อแล้วไม่ถูกถามซ้ำ ลิงก์เชิญจะรอจนตั้งชื่อเสร็จก่อนค่อยเด้งขึ้นมา

## ระบบยศ (แบบ Discord) ในเซิร์ฟเวอร์ที่ไม่ใช่เซิร์ฟเวอร์กลาง
เจ้าของเซิร์ฟเวอร์ (คนสร้าง) กดที่ชื่อเซิร์ฟเวอร์ (มุมซ้ายบน) → **ยศและสิทธิ์** แล้วทำได้ดังนี้
- **สร้างยศ** ตั้งชื่อ (ไม่เกิน 20 ตัว) เลือกสี และติ๊กสิทธิ์ที่ต้องการ สร้างได้สูงสุด 15 ยศต่อเซิร์ฟเวอร์ ยศที่ไม่ติ๊กสิทธิ์อะไรเลยใช้เป็นยศตกแต่งได้
- **สิทธิ์ที่เลือกได้ 7 อย่าง** เตะสมาชิก · แบนและปลดแบน · ปิดไมค์/ปิดหู · ย้าย/ตัดออกจากห้องเสียง · เปลี่ยนชื่อเล่น · ลบข้อความของคนอื่น · สร้าง/ลบช่อง
- **มอบยศ** กดที่ชื่อสมาชิกในรายชื่อด้านขวา จะเห็นปุ่มยศให้กดเพื่อให้/ถอน (หนึ่งคนมีได้หลายยศ สิทธิ์รวมกัน) คนที่ได้รับหรือถูกถอดยศจะมีข้อความแจ้ง
- **ลำดับยศ** ยศที่อยู่บนสุดของรายการสูงที่สุด เลื่อนขึ้นลงได้ด้วยปุ่ม ▲ ▼ คนที่ยศสูงกว่าจัดการคนที่ยศต่ำกว่าหรือไม่มียศได้ แต่จัดการคนที่ยศเท่ากัน/สูงกว่า และเจ้าของไม่ได้ ตัวเองก็ใช้กับตัวเองไม่ได้
- รายชื่อสมาชิกแยกกลุ่มตามยศ (เจ้าของ → ยศต่างๆ → ออนไลน์ → ออฟไลน์) ชื่อเป็นสีของยศ และการ์ดโปรไฟล์มีป้ายยศ
- ลบยศแล้วทุกคนที่มียศนั้นเสียสิทธิ์ทันที ถ้าออกจากเซิร์ฟเวอร์หรือถูกเตะ ยศจะหาย เซิร์ฟเวอร์ที่เคยตั้ง "แอดมิน" ไว้จากเวอร์ชันก่อน จะถูกแปลงเป็นยศชื่อ "แอดมิน" (เตะได้) ให้อัตโนมัติ
- เซิร์ฟเวอร์ตรวจสิทธิ์และลำดับยศจริงทุกครั้งที่มีคำสั่ง ไม่ใช่แค่ซ่อนปุ่ม

### เครื่องมือผู้ดูแล (ใช้ตามสิทธิ์ของยศ)
กดที่ชื่อสมาชิก (ในรายชื่อ ในแชต หรือในรายชื่อคนในห้องเสียง) จะเห็นส่วน "เครื่องมือผู้ดูแล" เฉพาะที่คุณมีสิทธิ์และใช้กับคนนั้นได้
- **เตะ** ออกจากเซิร์ฟเวอร์ (ถ้ายังมีรหัสเชิญ เขาเข้าใหม่ได้) · **แบน** ออกและกันเข้าใหม่ (ดู/ปลดแบนได้ที่ตั้งค่าเซิร์ฟเวอร์ → รายชื่อที่ถูกแบน)
- **ปิดไมค์** (ห้ามพูด) · **ปิดหู** (ไม่ได้ยินใครและพูดไม่ได้) สถานะนี้ติดกับบัญชี ออกแล้วเข้าห้องใหม่หรือถูกย้ายห้องก็ยังโดน จนกว่าผู้ดูแลจะปลด คนในห้องเห็นไอคอน 🔒 ข้างชื่อ
- **ย้ายไปห้องเสียงอื่น** หรือ **ตัดออกจากห้องเสียง**
- **เปลี่ยนชื่อเล่น** (เฉพาะในเซิร์ฟเวอร์นี้ ข้อความใหม่ในช่องและชื่อในห้องเสียงจะใช้ชื่อเล่น ชื่อบัญชีไม่เปลี่ยน เว้นว่างเพื่อล้าง)

**ข้อจำกัดที่ต้องรู้ (พูดตรงๆ)**
- ภาพและเสียงส่งตรงระหว่างผู้ใช้ (WebRTC) ไม่ผ่านเซิร์ฟเวอร์ การ "ปิดไมค์/ปิดหู" จึงบังคับผ่านแอปของแต่ละคน: แอปของคนที่ถูกปิดจะปิดไมค์และล็อกปุ่ม และแอปของทุกคนในห้องจะไม่เปิดเสียงของเขา แต่คนที่แก้โค้ดแอปตัวเองอาจส่งเสียงได้ ถ้าเจอกรณีแบบนี้ให้ใช้ "ตัดออกจากห้อง" หรือ "แบน"
- **แบนผูกกับบัญชี** ไม่ใช่กับตัวบุคคลหรือเครื่อง ถ้าคนที่ถูกแบนล้างข้อมูลเบราว์เซอร์จะได้บัญชีใหม่ (ระบบมีตัวจำกัดการสร้างบัญชีใหม่ต่อ IP เบื้องต้น) ถ้าเจอปัญหาจริงจังควรเปลี่ยนรหัสเชิญของเซิร์ฟเวอร์เพิ่ม
- "เตะ" ไม่ใช่ "แบน" คนที่ถูกเตะเข้ามาใหม่ได้ถ้ามีรหัสเชิญเดิม

## รหัส Dev (ผู้พัฒนา) และเซิร์ฟเวอร์กลาง
เซิร์ฟเวอร์กลาง "QuietSpace" ไม่มีเจ้าของและไม่มีระบบยศ แต่มี **ยศ Dev** สำหรับคุณคนเดียว (หรือคนที่คุณให้รหัส):
- ใส่รหัสที่หน้า **โปรไฟล์ (อวตารของฉัน) → รหัสผู้พัฒนา (Dev)** กด "ใช้รหัส Dev" จะมีป้าย DEV ข้างชื่อ และในรายชื่อสมาชิกของเซิร์ฟเวอร์กลางจะมีกลุ่ม 🛠️ Dev กด "ออกจากโหมด Dev" ได้ทุกเมื่อ (หมดอำนาจทันที)
- Dev ทำได้ในเซิร์ฟเวอร์กลาง: เตะ · แบน/ปลดแบน · ตัดออกจากห้องเสียง · ปิดไมค์ · ปิดหู · ย้ายห้อง · เปลี่ยนชื่อเล่น · ลบข้อความ · สร้าง/ลบช่อง · **รีเซ็ตเซิร์ฟเวอร์** (Dev ด้วยกันเตะ/แบนกันเองไม่ได้ และ Dev ไม่มีอำนาจในเซิร์ฟเวอร์ส่วนตัวของคนอื่น)
- **ที่มาของรหัส:** ในโค้ดเก็บเฉพาะค่าแฮช SHA-256 ของรหัส (ไฟล์ `src/hub.js` ค่า `DEV_KEY_HASHES`) ไม่มีรหัสจริงอยู่ในโค้ดหรือบน GitHub เลย จึงเดารหัสจากโค้ดไม่ได้ ระบบกันการเดารหัสด้วย (จำกัดความถี่ต่อการเชื่อมต่อและจำกัดจำนวนครั้งที่ผิดต่อช่วงเวลา)
- **เปลี่ยนรหัส/เพิ่มรหัสให้คนอื่น:** ตั้งตัวแปรลับ `DEV_KEYS` ที่ Cloudflare (Workers & Pages → โปรเจกต์ → Settings → Variables and Secrets → Add → ชนิด Secret) ใส่รหัสจริงได้หลายอันคั่นด้วยจุลภาค ถ้าจะเลิกใช้รหัสเดิมให้ลบค่าแฮชใน `DEV_KEY_HASHES` ออก (แก้ไฟล์แล้วอัปโหลด) คนที่เคยเปิดโหมด Dev ด้วยรหัสที่ถูกยกเลิกจะหมดสิทธิ์ทันที (ธง Dev ตรวจกับรหัสปัจจุบันทุกครั้ง)
- **ห้ามส่งรหัส Dev ให้ใครที่ไม่ไว้ใจ** และอย่าพิมพ์ในแชต รหัสนี้ให้อำนาจเตะ/แบน/รีเซ็ตเซิร์ฟเวอร์กลางทั้งหมด

### รีเซ็ตเซิร์ฟเวอร์กลาง
เฉพาะ Dev: กดที่ชื่อเซิร์ฟเวอร์ "QuietSpace" → ตั้งค่า → **เครื่องมือ Dev** → พิมพ์ "รีเซ็ต" เพื่อยืนยัน → กดปุ่มรีเซ็ต (ย้อนกลับไม่ได้) สิ่งที่เกิดขึ้น
- ตัดทุกคนออกจากห้องเสียง ลบข้อความทุกช่อง (รวมไฟล์แนบ) ลบห้องที่ผู้ใช้สร้างเพิ่มทั้งหมด เหลือ 4 ช่องตั้งต้นเหมือนตอนสร้างครั้งแรก (ทั่วไป แนะนำตัว ห้องต้อนรับ ห้องอ่านหนังสือเงียบๆ)
- เอาสมาชิกทุกคนออก ล้างรายชื่อแบน ชื่อเล่น และสถานะปิดไมค์ แล้วสร้างรหัสเชิญใหม่ (รหัสเก่าใช้ไม่ได้)
- ลบ **บัญชีที่ไม่เคยตั้งชื่อ** (ชื่อ "ผู้มาใหม่") ที่ออฟไลน์อยู่และไม่มีเพื่อน ไม่มีแชตส่วนตัว ไม่ได้เป็นสมาชิก Pro และไม่ได้เป็นเจ้าของเซิร์ฟเวอร์ใด ส่วนบัญชีที่ตั้งชื่อแล้วจะไม่ถูกลบ
- คนที่ออนไลน์อยู่ตอนกดรีเซ็ตจะยังอยู่ในเซิร์ฟเวอร์ใหม่ ส่วนคนอื่นจะถูกเพิ่มกลับให้อัตโนมัติ **ครั้งเดียว** เมื่อเปิดแอปครั้งถัดไป (ถ้าเขาออกจากเซิร์ฟเวอร์กลางเองหลังจากนั้นจะไม่ถูกดึงกลับ) รายชื่อสมาชิกจึงค่อยๆ เริ่มนับใหม่จากคนที่กลับมาจริงๆ
- **ข้อมูลจริงบนเว็บของคุณ** จะถูกรีเซ็ตเมื่อคุณกดปุ่มนี้หลังอัปเดตเวอร์ชันนี้ขึ้นเว็บแล้วเท่านั้น (ไม่ได้ถูกรีเซ็ตอัตโนมัติตอนอัปโหลดโค้ด)

## ให้อวตารขยับตามกล้อง และโหมดไม่เปิดเผยหน้า
กล้องจับใบหน้าด้วย MediaPipe Face Mesh ในเบราว์เซอร์ของคุณเอง (ภาพกล้องไม่ถูกส่งไปที่ไหนเพื่อประมวลผล) แล้วแปลงเป็นท่าทางให้อวตารทำตาม: หันหน้า เงยก้ม เอียงศีรษะ กะพริบตาซ้ายขวา อ้าปาก ยิ้ม ยกคิ้ว กลอกตา และเอนตัวตามตำแหน่งใบหน้า

- **ปุ่ม "อวตารขยับตามกล้อง"** ในห้องเสียง (และปุ่มทดลองในหน้า "อวตารของฉัน") ครั้งแรกจะให้ยืนหน้ากล้องมองตรงประมาณ 1 วินาทีเพื่อปรับค่ากลาง
- **โหมดไม่เปิดเผยหน้า** เปิดติดตามโดยไม่กดเปิดกล้อง = ไม่มีใครเห็นภาพกล้องของคุณเลย คนอื่นเห็นแค่อวตารที่ขยับตามคุณ ถ้าเปิดกล้องด้วยจะเห็นทั้งภาพกล้องและอวตาร
- **การส่งให้คนอื่น** ส่งเฉพาะตัวเลขท่าทาง 20 ไบต์ ประมาณ 20 ครั้งต่อวินาที ผ่านช่องข้อมูลตรงระหว่างผู้ใช้ (WebRTC DataChannel) ไม่ผ่านเซิร์ฟเวอร์ ไม่มีภาพหรือวิดีโอ เซิร์ฟเวอร์รู้แค่ว่าใครกำลังติดตามอยู่ (ไว้แสดงป้าย)
- **ข้อจำกัดที่ควรรู้**
  - ตัวติดตามโหลดจาก CDN (jsDelivr/unpkg) ราว 10 MB ครั้งแรก ต้องมีอินเทอร์เน็ต และต้องเปิดเว็บผ่าน https (หรือ localhost) กล้องถึงจะทำงาน
  - ทดสอบในห้องแล็บด้วยวิดีโอจำลองและภาพใบหน้า ยังไม่ได้ทดสอบกับเว็บแคมจริงหลายรุ่นและหลายแสง ถ้าแสงน้อยหรือใบหน้าไม่อยู่ในกรอบจะแสดงข้อความ "ไม่เห็นใบหน้า"
  - การประเมินสีหน้า (ยิ้ม คิ้ว) เป็นค่าประมาณ ยังไม่มีการติดตามแขนหรือมือ อวตารขยับแค่ศีรษะ ใบหน้า และการเอนตัว
  - คนอื่นต้องใช้เว็บเวอร์ชันนี้ถึงจะเห็นอวตารขยับตามคุณ เครื่องที่ช้ามากอาจกระตุก ปิดการติดตามได้ทุกเมื่อ

## หน้าตาและระบบแบบ Discord
เลย์เอาต์เหมือน Discord แต่แถบเซิร์ฟเวอร์อยู่ด้านบน: แถบเซิร์ฟเวอร์ (บน), รายการช่องหรือแชตส่วนตัว (ซ้าย), พื้นที่หลัก และรายชื่อสมาชิกพร้อมสถานะ (ขวา) ใช้ได้ทั้งโหมดสว่าง มืด และตามระบบ (ตั้งในหน้าโปรไฟล์) และบนมือถือรายการช่องกับรายชื่อจะเป็นลิ้นชักเลื่อนออกมา

- **ช่องข้อความ (#)** ข้อความจัดกลุ่มตามคนส่ง ตอบกลับ แก้ไข ลบข้อความของตัวเอง ใส่รีแอคชัน 10 แบบ ตัวหนา/เอียง/โค้ด แสดง "กำลังพิมพ์..." จุดบอกช่องที่ยังไม่ได้อ่าน
- **ช่องเสียง (ลำโพง)** กดเข้าแล้วเป็นห้อง 3 มิติเดิม มีกล้อง ไมค์ ปิดเสียงทุกคน พื้นหลัง เสียงบรรยากาศ และแชตของห้องนั้น แผงสถานะเสียงกับการ์ดโปรไฟล์ (ไมค์ หูฟัง ตั้งค่า) อยู่ **ด้านบนของแถบซ้าย**
- **สร้างช่อง** กดเครื่องหมาย + ข้างหมวดช่อง ตั้งชื่อ คำอธิบาย และจำนวนคนสูงสุดสำหรับช่องเสียง ลบห้องได้ดังหัวข้อ "ลบห้อง" ด้านล่าง

ไฟล์ `QuietSpace-preview.html` เปิดดูได้ทันทีโดยไม่ต้องมีเซิร์ฟเวอร์ แต่คนอื่นในนั้นเป็นบอทจำลองเพื่อให้เห็นการทำงาน (บอท "มินท์" เป็นสมาชิก Pro จำลองให้เห็นกรอบและป้าย ✦) ข้อมูลในนั้นอยู่แค่ในหน้าต่างนั้น ลิงก์เชิญใช้ข้ามเครื่องไม่ได้ ในพรีเซนต์นี้สมัคร Pro ได้แบบจำลอง อัปโหลดไฟล์ได้ (เก็บในหน่วยความจำของแท็บ หายเมื่อรีเฟรช) ใช้กับเพื่อนจริงต้องดีพลอยขึ้น Cloudflare

## อัปเดตผ่าน GitHub (ถ้าเชื่อม Workers Builds ไว้)

1. เปิดรีโป GitHub ของโปรเจกต์ > Add file > Upload files
2. ลากโฟลเดอร์ `public` โฟลเดอร์ `src` และไฟล์ `README.md` `wrangler.jsonc` `package.json` จากโฟลเดอร์ที่แตกใหม่ไปวาง (ไฟล์ชื่อซ้ำจะถูกแทนที่) หมายเหตุ: ถ้าคุณเคยเปิด R2 และลบ `//` ใน `wrangler.jsonc` ไว้แล้ว อย่าอัปโหลดทับด้วยไฟล์ใหม่ที่ยังมี `//` อยู่ (หรือแก้ซ้ำอีกรอบ)
3. กด Commit changes แล้วรอ 1-2 นาทีให้ Cloudflare สร้างใหม่ จากนั้นเปิดเว็บแล้วกด Ctrl+F5
